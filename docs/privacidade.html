Política de Privacidade – GesCon News

Última atualização: 24/11/2026.

O que o app faz

O GesCon News usa a autorização da conta Google do contrato Integridade Estrutural apenas para enviar o vídeo diário da TV ao YouTube e colocá-lo em uma playlist do canal dessa conta.

Dados acessados

O app acessa somente o que é necessário para essa tarefa: criar playlists e enviar vídeos no canal autorizado. Ele não lê vídeos de terceiros, comentários, e-mails, contatos nem outros dados da conta.

Armazenamento e compartilhamento

A credencial de acesso fica guardada como segredo no repositório privado de configuração do GitHub e é usada apenas pela rotina automática. Nenhum dado do Google é vendido, compartilhado com terceiros ou usado para publicidade. O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

E-mails de aviso

Usuários do painel podem cadastrar o próprio e-mail para receber um aviso quando o vídeo do dia for postado. O e-mail é usado apenas para esse aviso e pode ser removido a qualquer momento.

Revogação e contato

O acesso pode ser revogado em myaccount.google.com/permissions. Dúvidas: contratoestrutural@gmail.com.
